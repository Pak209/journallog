## Decisions and experiments

- **Platform:** Desktop first; macOS is the primary target and Windows runs alongside it. The named reference machine is a Mac mini M4 with 16 GB, while Windows/IL2CPP support was deferred because the required modules were not installed.
- **Input:** A measured failure of the legacy Input Manager with a Switch Pro-class controller triggered [Decision #38](https://github.com/Pak209/Holocity/commit/191d817ced4729d5cda3a2b2fc0277cab5b713d7): use Unity Input System in Both mode, map semantic controls, and vary only glyph presentation by device.
- **Dialogue:** Keep short, modern, speaker-specific lines; retain voice spots and terminal help trees; remove gambling metaphors. The content rules were carried into the generated library and witness pass.
- **Collaboration:** The team formalized a [Fable lead-chair/Astra specialist split](https://github.com/Pak209/Holocity/commit/962fe9da7b9b593dd380b6d7fbc238064288719c) and added an [atomic-write rule after a shared-log race](https://github.com/Pak209/Holocity/commit/b760eb35f7a3c273ef9bdc7bfb55ba43786a9781).
